# RaceDay System Planning

## 1. Project Overview

RaceDay is a web-based event management system designed specifically for the South African road running, walking and cycling community.

The system will allow Event Organisers to create and manage events, categories and participant results. Participants will be able to browse upcoming events, enter events, track their performance history and access race-day information such as weather and route information.

## 2. User Roles

The system will support two distinct user roles:

### Organiser

Organisers will be able to:

- Create events
- Edit events
- Delete events
- Create and manage event categories
- View event enrolments
- Capture participant results
- Manage participant results

### Participant

Participants will be able to:

- Create an account
- Log in
- Browse upcoming events
- View event details
- Enter an event
- Select an event category
- View their enrolments
- View their results and performance history
- View route information
- View weather information

## 3. Main System Functions

The RaceDay system will provide functionality for:

- User registration and authentication
- User profile management
- Event management
- Event category management
- Participant enrolments
- Participant results
- Route information
- Weather information
- Event images

## 4. Planned Technology

The system will be developed progressively across three parts.

### Part 1

- Entity Relationship Diagram (ERD)
- REST API endpoint plan
- SQL Server database script

### Part 2

- C# RESTful API
- SQL Server database integration
- Unit testing
- GitHub Actions CI/
